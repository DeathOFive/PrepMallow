# PrepMallow

PrepMallow is a free toolkit for getting images, PDFs, and other files ready for online forms, email, and sharing. Compress a photo to a target KB size, turn several pictures into one PDF, or check whether a file meets an upload limit.

**[Open PrepMallow on the web](https://saaimsohail.com/prepmallow/) · [Download PrepMallow for Android](https://github.com/DeathOFive/PrepMallow/releases/download/v1.0.1-preview/PrepMallow-v1.0.1.apk)**

## Install on Android

PrepMallow for Android bundles all 17 tools for offline use. Version 1.0.1 adds animations for tool screens, file selection and previews, with support for reduced motion. It requires **Android 10 or newer** and **Android System WebView 110 or newer**.

1. Download `PrepMallow-v1.0.1.apk` on your Android phone.
2. Open the APK from Downloads. If Android prompts, choose **Allow from this source** for the app that opened it, then return and tap **Install**.
3. Open **PrepMallow**, choose a tool and select a file. Tap **Save** or **Share** when your result is ready.

This build installs alongside the original `v1.0.0-preview`. [Release notes](https://github.com/DeathOFive/PrepMallow/releases/tag/v1.0.1-preview).

## What you can do

| Need | Tools |
| --- | --- |
| Make an image fit a form | [Compress images](https://saaimsohail.com/prepmallow/tools/compress-image/) to a target size such as 100 KB or 200 KB, [resize](https://saaimsohail.com/prepmallow/tools/resize-image/) to exact pixel dimensions, or [convert](https://saaimsohail.com/prepmallow/tools/convert-image/) HEIC, JPG, PNG, and WebP images. |
| Prepare a PDF | [Combine photos into one PDF](https://saaimsohail.com/prepmallow/tools/images-to-pdf/), [merge PDFs](https://saaimsohail.com/prepmallow/tools/merge-pdf/), [reorder, rotate, or extract pages](https://saaimsohail.com/prepmallow/tools/organize-pdf/), [export PDF pages as images](https://saaimsohail.com/prepmallow/tools/pdf-to-images/), or [compress a scanned PDF](https://saaimsohail.com/prepmallow/tools/compress-pdf/). |
| Get files ready to share | [Add a text watermark](https://saaimsohail.com/prepmallow/tools/watermark-file/), [remove photo metadata](https://saaimsohail.com/prepmallow/tools/remove-image-metadata/), [rename files in batches](https://saaimsohail.com/prepmallow/tools/rename-files/), or [create a ZIP](https://saaimsohail.com/prepmallow/tools/create-zip/). |
| Check before uploading | [Check a file](https://saaimsohail.com/prepmallow/tools/check-file/) against a size, format, or image dimension requirement. |

## Example

A form asks for a JPG under 200 KB and exactly 600 × 600 pixels. Open **Compress images**, set the size limit and dimensions, then save the result. Use **Check file details** to verify the copy before submitting it.

## File privacy

PrepMallow processes the files you select on your device. The Android app works offline, and the web version processes your files in your browser. [Read about file handling](https://saaimsohail.com/prepmallow/privacy/).
